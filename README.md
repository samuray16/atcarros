# Projeto de Veículos (AtCarros) 🚗✨

Repositório dedicado ao desenvolvimento de um projeto web com temática automotiva, focado na exibição, listagem ou catalogação de veículos com uma interface moderna, limpa e responsiva.

---

## 🚀 Funcionalidades

- **Catálogo de Veículos:** Exibição estruturada de informações, modelos ou características de carros.
- **Interface Moderna:** Layout atraente e intuitivo para melhor experiência do usuário.
- **Responsividade:** Design adaptável para diferentes tamanhos de tela (computadores, tablets e smartphones).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo e dos elementos visuais.
- **CSS3:** Estilização de layouts, cores, espaçamentos e design responsivo.
- **JavaScript (Vanilla):** Implementação de interatividade e dinamismo na aplicação.
